Yuclid custom rules
===================

Custom rules let Newclid use additional geometric theorems without adding a
hardcoded C++ matcher. Yuclid matches them alongside its built-in rules.

Start with :doc:`setup` to run an example. The remaining pages explain the
components and how to extend them.
